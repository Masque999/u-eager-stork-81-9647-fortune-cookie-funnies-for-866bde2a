# Fortune Cookie Funnies for Engineers

One line, at most 120 characters: a fortune cookie message for engineers.

Entry: `You will meet a tall, dark stranger: your own code, at 3 a.m., asking why you ever wrote it this way.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
